AZIBO STUDIO — Setup & Deployment Guide

Overview

AZIBO STUDIO is an AI video-generation platform built with Next.js, Firebase, Paystack, Cloudinary, and Pika Kling 3.0 Turbo.

AZIBO STUDIO uses a single universal Text-to-Video generation system. Users describe the video they want through text prompts and can generate different visual styles, including:

- Animals
- Realistic humans
- 3D animation
- Anime

The current generation system supports:

- Text-to-Video generation only
- 5, 10, and 15-second videos
- 720p and 1080p resolution
- 16:9, 9:16, and 1:1 aspect ratios
- Pika Kling 3.0 Turbo
- Previewing generated videos inside AZIBO STUDIO
- Downloading generated videos
- AZIBO STUDIO watermark processing for free users and the owner

Production readiness should only be claimed after the current application has successfully passed build, deployment, authentication, payment, database, and video-generation testing.
